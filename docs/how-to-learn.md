# How to learn with this repo

1. **Predict before you run.** Write down the output you expect, then run it. The gap between the two is where learning happens.
2. **Read errors from the bottom up.** The last line says what went wrong; the lines above say where. Try for 10 minutes before asking anyone (or any AI).
3. **Type, don't paste.** Typing the examples yourself builds the habit and shows you what you don't yet understand.
4. **Explain it out loud.** After each lesson, close it and explain the idea in one minute. Where you stall is what to re-read.
5. **Keep a tiny log.** Three lines a day: learned, confused by, tomorrow.
6. **Commit every day.** Small is fine. A visible streak is motivating.
7. **Review on the last day of the week.** Redo your weakest exercise from memory.

## Daily shape (about 3 hours)
| Block | Time | What |
|---|---|---|
| Learn | 1–1.5 h | One concept from the module |
| Build | 1–1.5 h | Apply it in the week's project |
| Drill | 20 min | One coding challenge |
| Wrap-up | 10 min | Write the three lines above |

On a short day, do Learn and Wrap-up. Never skip the wrap-up.
