# Docs

Guides for planning your study and getting the most out of the lessons.

| File | What it is | Read it when |
|---|---|---|
| [12-week-plan.md](12-week-plan.md) | The typical daily shape, the three phases (Python, Django, FastAPI), checkpoints at weeks 4, 9 and 12, and the portfolio tie-in | Before you start, and whenever you fall behind |
| [how-to-learn.md](how-to-learn.md) | Learning habits (predict, type, explain), the daily block structure, and the weekly review | Before your first lesson |
| [interview-questions.md](interview-questions.md) | The question bank for the Day 6 review, grouped by module, with blank answer lines | On Day 6 of each week |
| [drills.md](drills.md) | The Drill block's problem list: one easy HackerRank problem a day, grouped by week and module | Every day, in the 20-minute Drill block |

Day-by-day detail is in each `WEEK-N.md` file, for example [python/WEEK-1.md](../python/WEEK-1.md) and [django/WEEK-5.md](../django/WEEK-5.md).

The repo's [root README](../README.md) has the module list and the roadmap.
