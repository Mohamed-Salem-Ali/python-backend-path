# Deploy checklist: Gameya

Use this file for each deploy of the Gameya project, and keep the filled-in copy in your own notes. The public repo keeps the blank template. Mark each item Done, Skipped (with the reason), or Failed (with what you did next).

Deployed by: ____________ Date: ____________ Commit: ____________

## 1. Before the deploy
- [ ] `pytest` passes for every test file in `circles/tests/`, or each failing test is named and explained
- [ ] `python manage.py check --deploy` reports no issues, with `DJANGO_PRODUCTION=1` and a long key set
- [ ] `python manage.py collectstatic --noinput --dry-run` runs without an error
- [ ] `requirements.txt` lists gunicorn, whitenoise and psycopg, each with a version range
- [ ] `render.yaml` matches the Render service settings (start command, build command, variables)
- [ ] No secret is in git: `git grep -n "SECRET_KEY\|DATABASE_URL" -- ':!*.md'` returns only code that reads the variables

## 2. Render settings (fill in once, check on each deploy)
- [ ] Service type: Web Service. Runtime: Python. Region: ____________
- [ ] Root Directory: `django/gameya_site`
- [ ] Build Command: `pip install -r requirements.txt && python manage.py collectstatic --noinput`
- [ ] Start Command: `python manage.py migrate --noinput && gunicorn config.wsgi:application --bind 0.0.0.0:$PORT`
- [ ] Health Check Path: `/`
- [ ] `PYTHON_VERSION` = 3.12.6
- [ ] `DJANGO_PRODUCTION` = 1
- [ ] `DJANGO_SECRET_KEY`: generated by Render, not typed anywhere
- [ ] `DJANGO_ALLOWED_HOSTS` = the service host, for example `gameya-xxxx.onrender.com`
- [ ] `DATABASE_URL` copied from the PostgreSQL service in the same region

## 3. The deploy
- Build log: the build finished with no error, and `collectstatic` reported the number of static files it copied: ____
- Start log: the migrations ran (list the last migration name: ____________)
- Start log: gunicorn reports that it is listening on `0.0.0.0` and the port: ____________
- Deploy time (from the push to a live site): ____ minutes

## 4. Smoke tests (run on the live URL, over HTTPS)
- [ ] `http://` redirects to `https://` (open the plain address and check the final address)
- [ ] The home page loads with status 200
- [ ] The gameya list (`/gameyas/`) loads, and a gameya page shows its members
- [ ] The admin login page loads with its CSS, and an admin user can log in (use a staff account, not a password in this file)
- [ ] `POST /api/jwt/token/` with a user's username and password returns an `access` token
- [ ] A `GET` to `/api/gameyas/` returns JSON
- [ ] A page that does not exist shows a plain 404, with no traceback and no settings
