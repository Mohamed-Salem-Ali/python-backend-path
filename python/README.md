# Python (weeks 1–4, plus module 12 in week 10)

Start with [WEEK-1.md](WEEK-1.md). Most module folders have a `lesson.md` and an `exercises.py`. Modules 13 and 15 differ (see the table). Run an exercise from the repo root:

```bash
python python/03-collections/exercises.py
```

A passing file prints `All checks passed`. Week projects live in `week-N-project/`, and the capstone in `15-capstone-task-tracker/`.
