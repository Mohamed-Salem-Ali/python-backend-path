# Python (weeks 1–4)

Start with [WEEK-1.md](WEEK-1.md). Each module folder has a `lesson.md` and an `exercises.py`; run an exercise file from the repo root:

```bash
python python/03-collections/exercises.py
```

A passing file prints `All checks passed`. The week's project lives in `week-N-project/`.
