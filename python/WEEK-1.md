# Week 1: Environment, syntax, collections, control flow

Goal by Saturday: write small programs that read input, loop, store data in lists and dicts, and make decisions, and explain how each part works.

Daily shape: **Learn 1–1.5 h → Build 1–1.5 h → Drill 20 min → Wrap-up 10 min** (see [the plan](../docs/12-week-plan.md)).
On a short day (2 h): do Learn + Wrap-up only.

| Day | Learn | Build / exercises | Drill |
|---|---|---|---|
| **1 (tonight)** | [01 Environment & tooling](01-environment-tooling/lesson.md) | `01-environment-tooling/exercises.py`, make your first venv and a `hello.py` | 1 easy problem (print/format) |
| **2** | [02 Syntax & data types](02-core-syntax-data-types/lesson.md) part 1: numbers, strings | exercises 1–5 | 1 easy string problem |
| **3** | 02 part 2: booleans, None, dynamic typing, truthiness | exercises 6–10, finish file | 1 easy problem |
| **4** | [03 Collections](03-collections/lesson.md): list, tuple | exercises 1–6 | 1 easy list problem |
| **5** | 03: dict, set, mutability | exercises 7–12, finish file | 1 easy dict problem |
| **6** | [04 Control flow](04-control-flow/lesson.md) | exercises, then the **week project** | 1 problem |
| **Review day** | Redo your weakest exercise from memory | Finish and run the project, commit | Write 2–3 interview Q&As |

(Move the review/ship work to Day 6 if you take a rest day on Day 7. The plan has you work six days.)

## Checkpoint (end of week)
Without notes you can:
- [ ] Create and activate a venv, install a package, and run a script
- [ ] Explain what `==` vs `is` do, and why `0.1 + 0.2 != 0.3`
- [ ] Slice a string and a list, and explain what slicing returns
- [ ] Choose between list, tuple, dict and set for a given problem
- [ ] Explain why changing a list inside a function changes the caller's list
- [ ] Write a `for` loop, a `while` loop and a comprehension for the same task
